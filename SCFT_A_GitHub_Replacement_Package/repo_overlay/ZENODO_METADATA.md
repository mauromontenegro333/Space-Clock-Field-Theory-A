## Description

Reproducibility and theorem-support package for the revised Space-Clock Field Theory A (SCFT-A) classical construction. It contains exact coefficient certificates, exact algebra checks, recomputed source-free and visible-loaded backgrounds, endpoint and contracting-branch data, all 42 finite-time linear responses, and a separate support directory for the newer local nonlinear vacuum Cauchy theorem.

The nonlinear theorem scope is local Hadamard well-posedness on the stated open strongly Dirac-regular component of a compact boundaryless three-torus, with existence, uniqueness, continuous dependence, higher-regularity persistence, constraint propagation, and continuation. Global stability, bounded-domain evolution, unrestricted visible matter, strong-coupling/radiative control, and quantum completion are not claimed.

The manuscript and technical-companion TeX/PDF files are intentionally not distributed in this repository.
