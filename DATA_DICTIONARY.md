# SCFT-A curvature-completion data dictionary

All numerical data on `main` belong to the intrinsic-spatial-curvature completion generated by `scft_curvature_completion.py`, except `inherited_background_figure.csv`, whose provenance is explicitly inherited from the supplied TeX.

Numerical values are binary64 approximations unless an exact expression is stored as a string in a JSON file.

## `coupling_input.json`

- `delta_decimal_input`: inherited decimal evaluation of the manuscript coupling parameter.
- `provenance`: statement that the decimal was inherited and not independently globally certified.
- `exact_definition`: manuscript equation identifier for the exact definition.
- `eta_R`: exact curvature-completion coefficient, `1/(2*kappa_m)`.
- `eta_R_Hd_squared`: exact dimensionless benchmark, `1/240`.
- `proof_scope`: exact interval over which the endpoint sign proof is independent of the decimal approximation.

## `exact_checks.json`

- `checks`: Boolean results of the 16 implemented exact symbolic checks.
- `number_passed`: number of passing checks; current value is 16.
- `eta_Hd_squared`: stored exact benchmark `1/240`.
- `endpoint_polynomial`: exact polynomial certificate as a symbolic string.
- `endpoint_coefficients_ascending`: coefficients of the endpoint polynomial in ascending powers of `X = p^2/H_d^2`.
- `witness_exact`: exact endpoint witness at `X = 120`.
- `witness_margin_above_460`: exact positive difference between the witness and 460.

## `loaded_background.csv`

Header:

`ln_a,Q,H,Q_prime,H_prime,D_s,Xi_s,W_s,scaled_constraint_residual`

- `ln_a`: `N = ln(a)`.
- `Q`: homogeneous clock norm.
- `H`: dimensionless Hubble variable `H/H_d`.
- `Q_prime`: `dQ/dN`.
- `H_prime`: `d(H/H_d)/dN`.
- `D_s`: scalar background derivative combination used by the response equations.
- `Xi_s`: `D_s + 3 B_Q^2/2` in the implemented normalization.
- `W_s`: scalar mixing quantity `2H - Q B_Q` in the implemented normalization.
- `scaled_constraint_residual`: normalized background-equation residual.

The file contains 8001 rows over `1 <= a <= 10`.

## `endpoint_spectrum.csv`

Header:

`p_squared_Hd_squared,K_d,V_d_Hd_squared`

- `p_squared_Hd_squared`: `p^2/H_d^2`.
- `K_d`: endpoint scalar kinetic coefficient.
- `V_d_Hd_squared`: endpoint restoring coefficient divided by `H_d^2`.

Values are evaluated from the exact rational formulas after conversion to binary64 for plotting.

## `response_summary.csv`

Header:

`j,k_Hd,maximum_observable_response,a_at_max,channel_at_max,channel_refinement,pointwise_refinement,lapse_residual,shift_residual,slip_residual,nfev`

- `j`: mode index, 0 through 41.
- `k_Hd`: `k/H_d`.
- `maximum_observable_response`: sampled maximum of the absolute value of the first six observable response channels.
- `a_at_max`: scale factor of that sampled maximum.
- `channel_at_max`: zero-based observable-channel index at the sampled maximum.
- `channel_refinement`: maximum channel-wise coarse/fine discrepancy normalized by `max(1,|fine|)`.
- `pointwise_refinement`: maximum pointwise coarse/fine discrepancy normalized by `max(1,|fine|)`.
- `lapse_residual`, `shift_residual`, `slip_residual`: normalized maximum residuals for the fine run.
- `nfev`: fine integrator right-hand-side evaluation count.

The file contains 42 rows.

## Representative `response_XX.csv` files

Header:

`ln_a,zeta_obs,Phi_N,Psi_N,delta_b_N,delta_gamma_N,delta_nu_N,zeta,u,delta_b,delta_gamma,delta_nu,vartheta_b,vartheta_gamma,vartheta_nu,alpha`

There are 1001 output rows per representative mode. `zeta_obs` and the following five Newtonian-gauge channels are the six-observable set used in the response maximum. The later variables are the stored evolution state and lapse variable.

## `all_responses.npz`

Keys:

- `N`: shape `(1001,)`; common `ln(a)` grid.
- `k`: shape `(42,)`; mode wavenumbers in units of `H_d`.
- `values`: shape `(42,1001,15)`.

`values` columns are zero-indexed:

0. `zeta_observable`
1. `Phi_N`
2. `Psi_N`
3. `delta_b_N`
4. `delta_gamma_N`
5. `delta_nu_N`
6. `zeta`
7. `u`
8. `delta_b`
9. `delta_gamma`
10. `delta_nu`
11. `vartheta_b`
12. `vartheta_gamma`
13. `vartheta_nu`
14. `alpha`

## `numerical_summary.json`

Stores the inherited numerical `delta`, the exact `eta H_d^2` benchmark, number of modes, global sampled response maximum, refinement maxima, maximum residuals, maximum background residual, and DOP853-versus-RK45 comparisons at `k/H_d = 0.03`, `10`, and `1000`.

## `inherited_background_figure.csv`

Header:

`log10_a,Q,N_T,log10_H_Hd`

These broad-range homogeneous figure coordinates were extracted unchanged from the supplied TeX. They are not output of `scft_curvature_completion.py` and have distinct provenance from `loaded_background.csv`.
